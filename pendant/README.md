# Compass: the virtual Circle pendant

An interactive 3D model and hardware simulator of the Circle pendant, made by our teammate in Google AI Studio and remixed into this repo.

* **On its own** (`npm install && npm run dev`): demo mode with sample friends.
* **With the Circle server** (`npm run setup && npm start` from the repo root, then open `/pendant/`): pair it from the phone app's Device tab and it becomes your live wearable.

Double tap the center jewel to deploy the arrow and send "thinking of you". Triple tap to ask the friend you're pointing at to call you. TEST SOS and the biometrics sliders feed Circle's real safety alerts.
